Assignment Tracker

A clean and lightweight web application designed to help teachers and students efficiently manage and track assignments. Built during a hackathon, this project focuses on simplicity, usability, and fast performance.

Overview

Assignment Tracker provides a straightforward interface to create, view, and manage assignments. The goal is to reduce friction in tracking academic tasks while maintaining a minimal and intuitive user experience.

Features

- Create and manage assignments
- View assignments in a structured list
- Track deadlines efficiently
- Clean and minimal user interface
- Fast and responsive performance

Tech Stack

- Frontend: React (Vite)
- Styling: Tailwind CSS
- Deployment: Vercel

To run the project locally:

cd assignment-tracker
npm install
npm run dev
